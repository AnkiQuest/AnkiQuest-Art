# Frozen launcher icons

The three headshots use the frozen flame as in Aki's `icon_frozen`.
The [generation record](generation.json) lists three candidates per
companion and their references. The image generation tool did not expose
its model identifier.

| Companion | Master | Candidate |
| --- | --- | --- |
| Ankilope | [`ankilope/icon_frozen.png`](../../ankilope/icon_frozen.png) | A |
| Bluma | [`cow/icon_frozen.png`](../../cow/icon_frozen.png) | C |
| Anki-tan | [`anki-tan/icon_frozen.png`](../../anki-tan/icon_frozen.png) | C |

The icons were checked at 48 px on light and dark backgrounds. The three
1254 × 1254 transparent RGBA masters follow the
[alpha cleanup](../alpha-cleanup/README.md). The
[measurements](measurements.json) record the hashes and the cleanup.
