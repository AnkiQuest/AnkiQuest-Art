# Ankilope and Bluma launcher moods

The happy, worried and sleepy headshots follow the corresponding Aki
icons. The [generation record](generation.json) names the frozen icons
used for the companions' faces and scarves, lists three candidates for
each mood, and identifies the six chosen pictures. The image generation
tool did not expose its model identifier.

The masters are 1254 × 1254 transparent RGBA PNGs, checked at 48 px on
light and dark backgrounds. The [measurements](measurements.json)
record the hashes and confirm the
[alpha cleanup](../alpha-cleanup/README.md) preserved pixels above alpha
4. All six icons are AGPL-3.0-or-later.
