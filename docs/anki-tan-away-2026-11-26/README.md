# Anki-tan’s away poses

The abandoned pose adds dust, a small cobweb and a second dark headband star.

The masters fit a centered 1050 × 1050 area on a transparent 1254 × 1254
canvas. They were compared with the neighboring poses at 64 px on light
and dark backgrounds.

The [prompts](prompts.md) record the existing references and OpenAI
built-in image generation instructions. The tool did not report a
model identifier. The [measurements](measurements.json) record framing
and the original and master SHA-256 hashes.
