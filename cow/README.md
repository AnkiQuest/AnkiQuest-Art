# Bluma

Canonical core masters for companion id `cow`: face, asleep, happy,
streak, sad, hopeful, frozen and neglected. All are 1254 px transparent
PNGs. They were first committed as AnkiQuest-Server's `static/bluma/`
(asleep as `sleeping.png`, happy as `celebrate.png`); the archive kept
byte-identical copies under those names until they were removed as
duplicates ([archive README](../archive/README.md#removed-duplicates)).

OpenAI `image_gen` generated the original images; the model identifier
was not exposed. [Provenance and prompts](../docs/bluma-core-2026-11/README.md).
The repository licence applies.
The appearance was approved in [the reviewed pull request](https://github.com/AnkiQuest/AnkiQuest-Desktop/pull/322#pullrequestreview-5919330018).
