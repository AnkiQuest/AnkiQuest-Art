# Anki-tan asset pack

Shigeyuki's Anki-tan asset pack v1.0
(https://shigeyukey.github.io/shige-addons-wiki/Anki-tan.html), as
imported into AnkiQuest-Server, minus the files that became Anki-tan's
masters. The pack's `meme` folder was never imported: its pictures reuse
other works. Licence and credit: [LICENSE](LICENSE) (CC BY-SA 4.0).

- `emoji/`: chibi faces, 512 px.
- `illust/`, `sticker/`: full-size illustrations.
- `sprite/idle`, `sprite/hello`: 24-frame animations, 720 px, plus 240 px
  animated PNGs.

Files moved out to be masters, unchanged:

| Pack file | Master |
|---|---|
| `icon.png` | `anki-tan/icon.png`; `anki-tan/face.png` is cut from it |
| `sticker/ankitan_lets_study.png` | `anki-tan/hopeful.png` |
| `emoji/Ankitan_00_smile.png` | `anki-tan/chibi/face.png` |
| `emoji/Ankitan_02_cry.png` | `anki-tan/icon_worried.png` |
| `emoji/Ankitan_09_fire_eyes.png` | `anki-tan/icon_happy.png` |
| `emoji/Ankitan_35_sleeping.png` | `anki-tan/icon_sleepy.png` |
| `sprite/hello/anki-tan-hello_0006.png` | `anki-tan/chibi/happy.png` |
| `sprite/idle/anki-tan_idle_0013.png` | `anki-tan/chibi/idle.png` |

The emoji, stickers and the first idle frame that were masters until
2026-11-21 are back here under their pack names: poses other than
`face` are full body, and a picture nothing uses stays in the
archive.

The pack is never exported to a client.
